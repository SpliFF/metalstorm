# Audio loudness report (offline, ffmpeg ebur128)

Generated by `tools/audiogen/build.py --loudness-report` against the rendered `.webm` files under `data/games/metalstorm/sounds/**`. Integrated loudness (I, LUFS) and true peak (dBTP) per `ffmpeg -af ebur128=peak=true`. No live stack needed — this is a static per-file measurement, not an in-game listen check (that's L-VERIFY's `client_eval` audio tap).

**`-70.0 LUFS` entries are an EBU R128 gating artifact, not silence** — the integrated-loudness gate needs a sustained block above threshold to report a real number, which very short one-shot clips (UI blips, small impacts) don't provide. True peak stays meaningful for those rows; cross-check against `sounds.lua`'s per-key `gain` for actual in-game level.
