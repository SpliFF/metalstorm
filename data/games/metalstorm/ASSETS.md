# Metalstorm asset license manifest

**Mandatory** (PLAN-metalstorm-beta-units.md §1): every imported/derived asset
gets a row BEFORE it lands in the tree. No row, no merge. This is the legal
record for a GPL-2.0 game shipping mixed-source art.

Sourcing rules (beta-units §1):

- **CC0 preferred** (Quaternius, Kenney, OpenGameArt-CC0): unrestricted, safest.
- **WZ2100 assets are GPL-2.0+, NOT public domain** — compatible with the game
  license but attribution + source-offer obligations apply. Fallback only.
- Generated models (the tank+mech PoC gate, PLAN-model-harness.md): record the
  generator + prompt/seed in Modifications.
- Everything is normalised through the one pipeline (beta-units §6):
  RH orient → scale → piece rename (`turret`/`barrel`/`tracks`/`muzzle`;
  clips `walk`/`idle`/`death`) → palette re-texture → `.glb` (engine metadata
  embedded via the `SPRINGRTS_geometry` extension, not a separate sidecar —
  see `objects3d/README.md`) → `.ktx2` into `objects3d/` / `unittextures/`.

**Allowed License strings** (validated by `client/src/core/assets-manifest.ts`,
task 2's CI-style check — `make test-client`/`make test-all`): `CC0` / `CC0-1.0` /
`Public Domain`; `CC-BY <version>`; `CC-BY-SA <version>`; `GPL-2.0-or-later` /
`GPL-2.0+`; `Original (...)` for project-authored art (in-house, no external
source); `Generated (...)` for AI-generated assets (record the generator +
prompt/seed in Modifications, per the sourcing rules above). Any string
containing "NC", "ND", "non-commercial", "personal use", "proprietary", etc.
fails loudly, as does any string not matching one of the classes above — the
check denies-by-default on an unrecognised license rather than guessing.
