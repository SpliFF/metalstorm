# sounds/ — native audio

Authored **`.webm`** (Opus) only (PLAN-metalstorm.md §9);
`gamedata/sounds.lua` references `.webm` names natively, so there is no
prune/extension-swap step by construction.

Generated by `tools/audiogen/build.py` from `tools/audiogen/manifest.json`
(2026-09-17 L-AUDIO pass) — self-authored layered synthesis, see
`tools/audiogen/README.md` for the sourcing rationale and known gaps.

- `weapons/` — 11 kinetic families, each a close (`<key>.webm`) + `_far`
  (`<key>_far.webm`) pair, switched at 900 elmos (switch not yet wired,
  see `tools/audiogen/README.md`)
- `impacts/` — metal / dirt / water × 2, plus `hit_rail` / `shield_hit`
- `explosions/` — `blast_{small,med,large,huge,air,water}`
- `deaths/` — one per audio death class (infantry, vehicle light/heavy,
  aircraft, ship, building)
- `ambience/` — wind / dust-gust / distant-artillery × {open, valley,
  urban} biome beds (loopable, non-positional)
- `ui/` — open/close/confirm/refuse/notice, radio-filtered
- `music/` — `music_{calm,tension,battle}`, 100-110s loops
- `efx/` — reverb impulse responses (`{open,valley,urban}.webm`) for
  `audio.ts`'s `setReverbPreset`
- `units/` — `engine_run.webm` loop

**Every asset needs a row in `../ASSETS.md` first** — `tools/audiogen/build.py`
enforces this by construction (writes `ASSETS.md` before rendering).
